Telegram AI Quiz Bot

An automated Telegram Quiz Bot for WBCHSE Class 12 students.

Features

- 🤖 AI-generated MCQs using Gemini API
- 📚 Subjects:
  - Biology
  - Mathematics
  - Chemistry
  - Physics
  - Bengali
  - English
- 📊 Telegram Quiz Polls
- ⏰ Automatic scheduling with GitHub Actions
- 🎯 One quiz sequence per day
- 🔀 Random daily start time
- ⏱️ 10-minute gap between subjects
- 🌐 PHP backend
- ☁️ Hosted on InfinityFree

Technology Stack

- PHP
- Gemini API
- Telegram Bot API
- GitHub Actions
- InfinityFree

Workflow

GitHub Actions
      ↓
send.php
      ↓
Gemini API
      ↓

      ↓

      ↓
